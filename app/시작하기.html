AI Motion Studio 시작하기

AI 모션그래픽 작업(기획 → 캐릭터 → 스타일프레임 → 스토리보드 → 샷 이미지 → 애니메틱 → 영상화 → 편집·AE)을 한 화면에서 이어 가는 개인 작업 앱이에요. AI는 각자 자기 계정으로 연결해서 써요.

1준비물 — Node.js 하나

nodejs.org에서 LTS 버전을 설치하세요 (한 번만). 앱 자체는 설치할 것이 없어요.

2실행

⬇ AI-Motion-Studio.zip 내려받기 — 웹에서 열었다면 여기서 받으세요

Windows

압축을 풀고 start.cmd를 더블클릭. 검은 창이 뜨고 브라우저에 앱이 열려요.

검은 창은 작업하는 동안 켜 두세요.

Mac

압축을 풀고 start.command를 더블클릭. 처음에 막히면 우클릭 → 열기, 또는 터미널에서 bash start.command

터미널 창은 작업하는 동안 켜 두세요.

앱 주소는 http://127.0.0.1:8790 — 내 컴퓨터 안에서만 열리는 주소예요.

3내 AI 연결하기

앱 왼쪽 아래 AI 연결(⚙)을 누르고, 내가 쓰는 것을 고르면 돼요. 여러 개 써도 되고, 단계마다 다르게 골라도 돼요.

내가 쓰는 것글 작업 (기획·프롬프트)이미지 · 영상준비
Claude 구독
Pro · Max		자동Higgsfield 계정이 있으면 자동Claude Code 설치 후 로그인. Higgsfield는 Claude 설정 → 커넥터에서 Higgsfield 켜기
ChatGPT 구독
Plus · Pro		자동ChatGPT · Sora (웹)에서 직접 — 앱이 프롬프트를 복사하고 사이트를 열어 줘요터미널에서 npm i -g @openai/codex → codex login
Gemini
구글 계정 · 베타		자동Gemini (웹)에서 직접터미널에서 npm i -g @google/gemini-cli → gemini 실행해 로그인
API 키
OpenAI · Gemini · Claude		자동OpenAI · Gemini 키면 이미지 자동 (GPT Image · Nano Banana)AI 연결 → 내 API 키에 붙여넣기. 쓴 만큼 요금이 나가요
Higgsfield · Midjourney · Kling 웹—웹에서 직접 (복사 → 사이트 → 결과를 칸에 Ctrl+V)각 사이트 로그인만

구독(Claude · ChatGPT · Gemini)은 2번처럼 start 파일로 열었을 때 내 컴퓨터에 로그인된 계정을 그대로 써요. API 키는 내 브라우저에만 저장되고, 프로젝트 백업 파일에도 들어가지 않아요.

4내 작업 · 옮기기 · 함께 쓰기

저장

작업은 지금 쓰는 브라우저에 자동 저장돼요. 다른 브라우저·컴퓨터와는 따로예요.

옮기기 · 전달

사이드바 ⬇ 백업으로 파일을 받고, 다른 곳에서 ⬆ 가져오기. 프로젝트를 다른 사람에게 넘길 때도 이 파일이면 돼요 (키는 안 들어가요).

크레딧 · 요금

작업 현황에서 단계별 사용량을 볼 수 있어요. 정확한 잔액은 각 플랫폼 사이트에서 확인하세요.

?자주 묻는 것

앱이 안 열려요 — 검은 창(터미널)에 뜬 주소 http://127.0.0.1:8790을 브라우저에 직접 넣어 보세요. "포트가 이미 사용 중"이면 이미 켜져 있는 거예요.

AI 연결에 '설치·로그인 필요'라고 나와요 — 표의 준비 칸대로 설치·로그인한 뒤 start 파일을 다시 실행하세요.

링크만으로 쓸 수는 없나요? — 웹에 올린 버전도 열 수는 있지만, 그때는 API 키와 웹에서 직접만 돼요. 구독 계정을 쓰려면 이렇게 내려받아 start 파일로 여세요.
