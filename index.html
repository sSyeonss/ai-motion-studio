궁금한 점

회원가입이 필요한가요?

아니요. 앱은 계정이 없어요. AI는 각자 쓰는 서비스의 API 키나 구독으로 연결해요.

내 작업은 어디에 저장돼요?

지금 쓰는 브라우저 안에만 저장돼요. 다른 컴퓨터로 옮기려면 왼쪽 아래 ⬇ 백업 내보내기 → 다른 곳에서 ⬆ 가져오기를 쓰세요. API 키는 백업에 들어가지 않아요.

요금이 드나요?

앱은 무료예요. AI를 쓰는 만큼 각자 연결한 서비스(API · Higgsfield 크레딧 등)에서 요금이 나가요. 작업 현황에서 단계별 크레딧 사용량을 볼 수 있어요.

휴대폰에서도 되나요?

열리긴 하지만 타임라인 편집 등은 큰 화면에 맞춰져 있어요. 컴퓨터 브라우저(Chrome · Edge · Safari)를 권해요.
